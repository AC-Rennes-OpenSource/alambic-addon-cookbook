# Addon de l'ETL Alambic - cookbook : atelier de développement

![Cook book](img/header.png "Cook book")

## Description du addon

Ce addon est destiné à collecter des exemples d'utilisation du produit Alambic qui
peuvent être repris pour le développement de addon métiers.

## Recettes

* Carpaccio de WEB services : illustration de la manière de consommer de la donnée exposée par un Webservice.
* Galette complète supplément LDAP illustration de la manière de manipuler de la donnée LDAP.
* Salade d'API et de requêtes XPATH illustration de la manière de produire un flux de donnée JSON  + requétage XPATH
* quiche-aux-legumes-anonymisee.xml : illustration du moyen d'anonymiser des données.
